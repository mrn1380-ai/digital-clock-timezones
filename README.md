# داشبورد مانیتورینگ وضعیت اتصال نوبیتکس و ساعت دیجیتال جهانی
# Nobitex Connection Status & World Timezones Dashboard

یک داشبورد پیشرفته، لحظه‌ای و مدرن فین‌تک جهت **بررسی و مانیتورینگ زنده وضعیت اتصال به صرافی ارز دیجیتال نوبیتکس (Nobitex)** همراه با **ساعت دیجیتال مناطق زمانی جهان** و نرخ‌های لحظه‌ای رمزارزها.

---

## 🌟 ویژگی‌های کلیدی (Key Features)

### ۱. مانیتورینگ زنده وضعیت اتصال به نوبیتکس (Live Connectivity Monitoring)
- **بررسی دوگانه (Dual-Probe Verification):**
  - **بررسی مستقیم مرورگر کاربر (Client-Side Direct Ping):** تست زنده اتصال از داخل مرورگر کاربر به سرورهای نوبیتکس.
  - **بررسی سرور بک‌اند (Backend Cloud VM Probe):** بررسی اتصال TCP سوکت پورت 443 و زمان برقراری ارتباط با نودهای لبه CDN ابرآروان نوبیتکس.
- **اندازه‌گیری میلی‌ثانیه‌ای تاخیر شبکه (Ultra-Low Latency Tracking):** ثبت زمان رفت‌وبرگشت پکت‌ها (RTT) با دقت بالا.
- **نمودار داینامیک تاخیر زمانی (Real-Time Latency Canvas Chart):** رسم زنده منحنی پینگ با گرادیان رنگی، آمار حداقل، میانگین و حداکثر پینگ و جعبه اطلاعات شناور (Hover Tooltip).
- **شاخص سلامت و پایداری (Uptime & Health Score):** محاسبه نرخ پایداری 100% و اتلاف صفر درصد بسته (0% Packet Loss).

### ۲. بررسی تفکیکی سرویس‌های اصلی نوبیتکس (Nobitex Service Health Matrix)
- 🌐 وب‌سایت اصلی نوبیتکس (`nobitex.ir`)
- ⚡ درگاه ارتباطی اصلی ای‌پی‌آی (`apiv2.nobitex.ir/v2/options`)
- 📊 موتور دفترچه سفارشات (`apiv2.nobitex.ir/v3/orderbook`)
- 📈 وب‌سرویس آمار بازار و قیمت‌ها (`apiv2.nobitex.ir/market/stats`)
- 🔄 درگاه وب‌سوکت قیمت‌های زنده (`wss://apiv2.nobitex.ir`)
- 📑 پرتال مستندات برنامه‌نویسان (`apidocs.nobitex.ir`)

### ۳. ساعت دیجیتال و مناطق زمانی جهان (Digital Clock & World Timezones)
- نمایش زنده و دقیق **ساعت رسمی ایران (تهران - IRST/IRDT)** با ثانیه‌شمار دیجیتال.
- نمایش تقویم **هجری خورشیدی (شمسی)** دقیق (مانند: پنج‌شنبه ۱۰ مهر ۱۴۰۵) و تاریخ میلادی.
- نمایش ساعت مراکز مالی جهان: **ساعت هماهنگ جهانی (UTC)، لندن، نیویورک، توکیو و دبی**.

### ۴. تابلوی قیمت‌ها و دفترچه سفارشات زنده نوبیتکس (Live Markets & OrderBook)
- جفت‌ارزهای محبوب بازارهای نوبیتکس شامل **BTC، ETH، USDT، SOL، TON، DOGE، XRP، TRX، ADA و SHIB**.
- تفکیک بازارهای تومانی (IRT) و تتری (USDT).
- دفترچه سفارشات (Order Book) عمق بازار با نوارهای گرافیکی حجم خرید (سبز) و فروش (قرمز).
- محاسبه خودکار فاصله خرید و فروش (Spread).
- نمایش معاملات اخیر (Recent Trades Stream) به صورت زنده.

### ۵. کنسول لاگ رخدادهای شبکه و تنظیمات پیشرفته (Live Event Logs & Diagnostics)
- جدول ثبت رخدادهای شبکه با مهر زمان دقیق، متد، وضعیت و تاخیر.
- مودال تست اختصاصی هاست یا پورت دلخواه (Custom Probe).
- کنترل فاصله زمانی بررسی خودکار (Auto-refresh interval: 3s, 5s, 10s, 30s, off).
- پشتیبانی از تم تاریک (Dark Mode) و تم روشن (Light Mode).
- پشتیبانی دو زبانه (فارسی / انگلیسی) با چیدمان راست‌به‌چپ (RTL) و چپ‌به‌راست (LTR).

## 🚀 نحوه اجرا (Getting Started)

### پیش‌نیازها
- Node.js نسخه 18 یا بالاتر
- npm

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای برنامه
```bash
npm start
```
سپس داشبورد روی آدرس `http://localhost:3000` در دسترس خواهد بود.

## 📡 اندپوینت‌های ای‌پی‌آی (REST API Endpoints)

- `GET /api/nobitex/ping` - اجرای فوری پروب نوبیتکس و دریافت خلاصه وضعیت و آمار
- `GET /api/nobitex/status` - دریافت آخرین وضعیت کش شده
- `GET /api/nobitex/markets` - دریافت لیست قیمت‌ها و تغییرات ۲۴ ساعته بازارهای نوبیتکس
- `GET /api/nobitex/orderbook/:symbol` - دریافت دفترچه سفارشات برای نماد انتخابی (مانند BTCIRT)
- `GET /api/nobitex/trades/:symbol` - دریافت آخرین معاملات نماد
- `POST /api/nobitex/custom-probe` - تست آدرس و پورت سفارشی نوبیتکس
- `GET /api/timezones` - دریافت لیست ساعت‌های جهانی
- `WS /` - استریم سوکت زنده تغییرات لتنسی، بازار و سفارشات
