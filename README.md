# توزیع آماری هزینه معامله در فیوچرز بایننس (USDⓈ-M)

داشبورد تحلیل **اسپرد و کارمزد بر حسب درصدی از قیمت** روی همهٔ نمادهای `PERPETUAL` بایننس،
به‌همراه **دسته‌بندی هزینه** و **استخراج عوامل مؤثر** روی تفاوت بین نمادها.

> داده از REST عمومی بایننس گرفته می‌شود؛ **نیازی به API Key نیست**.

---

## اجرا

```bash
npm install
npm run collect     # گرفتن دادهٔ واقعی و ذخیره در data/snapshot.json  (این کار را روی سیستمی اجرا کنید که به fapi.binance.com دسترسی دارد)
npm run dev         # http://localhost:3000
```

اگر سرور بتواند به بایننس وصل شود، داشبورد خودش زنده داده می‌گیرد و نیازی به `collect` نیست.
اگر وصل نشود: اول `data/snapshot.json` را نشان می‌دهد و در نبود آن، دادهٔ **نمایشی** با برچسب قرمز هشدار.

```bash
npm run collect:deep              # + کندل روزانهٔ ۷ روزه برای تخمین اسپرد میانگین ۲۴ساعته
npm run collect -- --fee=vip1     # با رده کارمزد دلخواه
npm test                          # تست واحد موتور محاسبه
```

## چه چیزی محاسبه می‌شود

| کمیت | فرمول | توضیح |
|---|---|---|
| میانه قیمت | `(bid + ask) / 2` | از بهترین سطوح دفترچهٔ سفارش |
| **اسپرد** | `(ask − bid) / mid × 10,000` | بر حسب bps؛ همان «درصد نسبت به قیمت» |
| **کف تیک** | `tickSize / mid × 10,000` | کمترین اسپرد ممکن با اندازه‌گام قیمت |
| هزینه یک‌طرفه | `takerFee + spread/2` | ورود با سفارش بازار |
| **هزینه رفت‌وبرگشت** | `2 × takerFee + spread` | بازده لازم برای سربه‌سر شدن |
| نوسان پارکینسون | `ln(H/L) / (2√ln2)` | از سقف/کف ۲۴ساعته |
| آمیهاد | `|بازده| / حجم` | نقدینگی (عدد بالاتر = بدتر) |
| اسپرد ۲۴ساعته | تخمین‌گر **Corwin–Schultz** | فقط در حالت عمیق (از کندل روزانه) |
| نوسان تحقق‌یافته | انحراف معیار لگاریتمی بازده روزانه | ۷ روز اخیر، فقط در حالت عمیق |

نرخ کارمزد پایه (قابل تغییر از نوار بالای داشبورد):
Maker `0.02%` / Taker `0.05%` و `−۱۰٪` در صورت پرداخت با BNB.
نرخ دقیق حساب خودتان را در صفحهٔ Fees بایننس چک کنید.

## وضعیت اتصال

داشبورد قبل از هر چیز **وضعیت اتصال به بایننس** را نشان می‌دهد: هر میزبان با یک درخواست سبک
(`/fapi/v1/time`) به‌صورت موازی بررسی می‌شود و نتیجه با کد خطا، تأخیر و **علت دقیق** گزارش می‌گردد:

| وضعیت | معنی |
|---|---|
| ✔ سالم | پاسخ معتبر — داده زنده در دسترس است |
| مسدود جغرافیایی | بایننس به IP شما پاسخ نمی‌دهد (HTTP 451) → نیاز به VPN یا شبکه دیگر |
| خطای DNS | دامنه resolve نمی‌شود (فیلتر DNS) |
| مسدود شبکه | فایروال/پراکسی یا قطع مسیر TLS |
| اتمام مهلت | پاسخی در زمان مقرر نرسید |
| سقف نرخ / خطای سرور | محدودیت سمت بایننس |

همین بررسی در `npm run collect` هم اجرا می‌شود؛ اگر شکست بخورد، علت دقیق چاپ می‌شود.

## تحلیل‌ها

1. **توزیع** — هیستوگرام لگاریتمی اسپرد + میانه/صدک‌ها/بیشینه.
2. **دسته‌بندی قاعده‌محور** — شش دستهٔ `T1…T6` بر اساس آستانه‌های ثابت اسپرد، به‌همراه سهم حجم، کف تیک و توصیهٔ اجرای سفارش.
3. **خوشه‌بندی داده‌محور** — `k-means` پنج‌بُعدی (لگاریتم اسپرد، حجم، کف تیک، نوسان) + شکست‌های طبیعی یک‌بعدی؛ برای راستی‌آزمایی مرزهای دستی.
4. **عوامل مؤثر** — سطل‌بندی نقدینگی/قیمت/کف تیک/نوسان/قدمت/دارایی تسویه و اندازهٔ اثر هرکدام.
5. **درخت تصمیم (CART)** — مهم‌ترین آستانه‌هایی که اسپرد را توضیح می‌دهند (عمق ۳، حداقل ۱۲ نماد در هر برگ).
6. **همبستگی اسپیرمن** — شدت و جهت رابطهٔ هر عامل با اسپرد.
7. **نقشه حرارتی قیمت × حجم** — سریع‌ترین راه برای یافتن «تلهٔ هزینه».

## ساختار

```
src/lib/binance.ts    اتصال به REST بایننس با failover + پروب وضعیت و دسته‌بندی خطا
src/lib/metrics.ts    محاسبهٔ هزینه، کف تیک، Corwin–Schultz، دسته‌بندی
src/lib/analyze.ts    هیستوگرام، خوشه‌بندی، عوامل، درخت تصمیم، همبستگی

src/lib/synthetic.ts  دادهٔ نمایشی برچسب‌دار (فقط وقتی بایننس در دسترس نیست)
src/app/api/market    مسیر سروری داشبورد
scripts/collect.ts    اسکریپت خط فرمان برای ذخیرهٔ اسنپ‌شات
```

## محدودیت‌ها

- اسپرد لحظه‌ای یک عکس در زمان است؛ در بازار پرنوسان تغییر می‌کند.
- هزینهٔ واقعی اجرا برای سفارش‌های بزرگ شامل **لغزش (Slippage)** است که این داشبورد آن را اندازه نمی‌گیرد.
- تخمین Corwin–Schultz برای بازارهای یک‌طرفه مقدار منفی می‌دهد و صفر می‌شود.
- هیچ توصیهٔ معاملاتی نیست؛ صرفاً تحلیل هزینه.
