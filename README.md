# رادار هزینه بایننس

داشبورد فارسی و واکنش‌گرا برای مقایسهٔ **اسپرد بهترین bid/ask** نمادهای فعال اسپات و فیوچرز USDⓈ-M و نمایش برآورد کارمزد پایه. بدون کلید API.

## اجرا

```bash
npm start
# http://localhost:3000
npm test
```

Node.js 20+ لازم است؛ وابستگی خارجی وجود ندارد. سرور روی `0.0.0.0:3000` گوش می‌دهد (با `PORT` قابل تغییر است).

## داده و محاسبه

- APIهای عمومی `exchangeInfo`، `ticker/bookTicker` و `ticker/24hr` بایننس؛ برای اسپات ابتدا `data-api.binance.vision` و سپس دامنه‌های اصلی، برای فیوچرز `fapi.binance.com`. اگر دسترسی سرور ناموفق باشد، مرورگر مستقیماً تلاش می‌کند. برای هر بازارِ مسدود، خطای دسترسی نشان داده می‌شود و دادهٔ ساختگی جایگزین نمی‌شود.
- فقط نمادهای `TRADING` با bid/ask مثبت و `ask > bid` نمایش داده می‌شوند؛ نمادهای بدون سفارش معتبر حذف می‌شوند. اسپات با `isSpotTradingAllowed=false` کنار گذاشته می‌شود.
- `spread (bp) = (ask − bid) / ((ask + bid) / 2) × 10000`؛ `roundtrip (bp) = spread + 2 × taker fee`. فرض قیمت میانی ثابت و اجرای سفارش بسیار کوچک است؛ لغزش، عمق سفارش، funding و تغییر قیمت لحاظ نشده‌اند.
- نرخ پایهٔ VIP0: اسپات maker/taker ده bp، برای جفت‌های مظنه USDC نرخ taker برابر ۹٫۵ bp؛ فیوچرز USDⓈ-M maker دو bp و taker پنج bp. کارمزد واقعی هر حساب، تخفیف BNB، برنامه‌های VIP و پروموشن جفت‌نماد ممکن است متفاوت باشد. [جدول رسمی بایننس](https://www.binance.com/en/fee/trading).
- تنظیم دستی نرخ‌های کارمزد از دکمه «تنظیم کارمزد» و نمایش توزیع اسپرد، کارمزد taker یا هزینهٔ رفت‌وبرگشت ممکن است. توزیع با سطل‌های ثابت bp؛ آمار میانه، چارک‌ها و صدک ۹۰. گروه‌بندی بر اساس نوع بازار، مظنه، گام قیمت نسبت به mid و چارک حجم ۲۴ساعته (فقط جفت‌های با مظنهٔ نزدیک دلار) است. «تفاوت عملی قابل‌توجه» به‌صورت قراردادی: حداقل ۱۰ نماد در هر گروه، نسبت میانه ≥۲ و اختلاف ≥۱ bp؛ **این آزمون معناداری آماری یا اثبات علیت نیست**.
- عکس فوری API است نه جریان لحظه‌ای / سری‌زمانی؛ کارمزدهای پایه مدل ثابت‌اند، نه مقدار دریافت‌شده از حساب کاربر. خروجی CSV از نمادهای فیلترشده است.

## تشخیص اتصال

اگر بازار ناموجود بود، در پیام هشدار گزینهٔ «علت اتصال را بررسی کن» را بزنید. این گزینه اتصال **سرور** و **مرورگر** را مستقل آزمایش می‌کند. قطع TLS به `example.com` هم از این محیط با `ECONNRESET` رخ می‌دهد؛ این خطای شبکهٔ میزبان است، نه API key یا فرمول محاسبه. ابزار بیرونی وب به مسیر عمومی اسپات `data-api.binance.vision` دسترسی دارد، ولی API اصلی و فیوچرز در خروجی همان ابزار پیام صریح `restricted location` می‌دهند. دامنه‌های جایگزین رسمی اسپات فقط برای خطای شبکه بررسی می‌شوند و هنگام پاسخ صریح محدودیت منطقه‌ای تلاش برای جابه‌جایی میزبان متوقف می‌شود. تست‌نت دادهٔ واقعی تولید نمی‌کند و جایگزین فیوچرز اصلی نیست.
